# Happy Birthday, Mumma! 🎂💗

A heartfelt, elegant, and mobile-first single-page birthday surprise website crafted with love from **Swasti** for her Mumma.

## 🌟 Highlights & Features
- **Warm Aesthetic & Palette:** Rose gold, warm pinks, champagne gold, and celebratory berry tones with glassmorphism and subtle glowing light effects.
- **Hero & Gift Unwrapping:** An animated landing section with floating balloons, sparkles, and a *"Tap to Open My Gift 🎁"* button triggering multi-burst confetti cannons and smooth auto-scroll.
- **Heartfelt Letter:** A styled letter card with a wax stamp, decorative ribbons, and progressive reveal of Swasti's heartfelt message.
- **Moments with Mumma Photo Gallery:** 6 memories displayed in Polaroid-inspired frames with gold accents and an interactive fullscreen Lightbox with swipe/keyboard navigation.
- **A Bouquet of Wishes:** Interactive flower cards that bloom with sparkle effects and sound when tapped.
- **Interactive Birthday Cake:** Interactive 3-tier cake with glowing candles that Mumma can blow out to reveal a celebratory greeting!
- **Music Box Melody:** Soft acoustic birthday instrumental synthesizer that can be toggled in the top corner (works seamlessly with zero external dependencies).

## 🚀 Easy Deployment

This project is completely static (Pure HTML, CSS, and Vanilla JS) with zero build steps or npm dependencies required.

### Deploying to Vercel
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import this repository and click **"Deploy"** (no build settings required).

### Deploying to Netlify / GitHub Pages
- **Netlify:** Drag and drop this folder directly into the Netlify dashboard.
- **GitHub Pages:** Go to repository **Settings > Pages**, select the `main` branch root folder, and save.
